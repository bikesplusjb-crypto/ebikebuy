Shimano STEPS error codes

Shimano STEPS and EP e-bike systems. Codes starting with W are warnings, which clear when conditions improve; codes starting with E are errors, which point to a possible fault. Shimano's E-TUBE PROJECT Cyclist app can read the code from the bike.

A short list, on purpose. These are the Shimano codes we could confirm in Shimano's own manuals. Most come from Shimano's Japanese manual for the E8080 system and are translated, so follow each source link for Shimano's exact wording. For any code not listed, use Shimano's official lookup at si.shimano.com/error.
  • E010System error
  • E013Drive unit firmware fault
  • E014Speed sensor may be out of position
  • E020Battery and drive unit not communicating
  • E021Battery not supported by this system
  • E022Battery doesn't meet system standards
  • E025Battery doesn't recognize the drive unit
  • E033Firmware not supported
  • E043Display firmware may be corrupted
  • E295Tampering detected
  • E299Safe Mode
  • W010Drive unit is hot
  • W011Speed can't be detected
  • W013Pedal sensor didn't start up properly
  • W020Battery temperature out of range
  • W032Wrong type of derailleur connected

We haven't verified that code yet, so we won't guess. Check Shimano's official error code lookup, or send us a photo of the display.
