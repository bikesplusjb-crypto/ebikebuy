Bosch 3-digit error codes

Bosch error 460
USB port error

There's a problem with whatever is plugged into the display's USB port.

Checked against Bosch's help center: October 23, 2026.

What Bosch says

Error at the USB port.

Bosch's recommended steps

  1. Remove the cable from the on-board computer's USB port.
  2. If the problem persists, contact your Bosch eBike dealer.

Summarized from Bosch's help page for error 460, checked October 23, 2026. Follow the link for Bosch's exact wording.

If it keeps coming back

If the code comes back after a restart, have it checked. A diagnostic tool can read the full fault history; Bikes Plus has them for Bosch and most other major motor systems.

Write down the code and what you were doing when it appeared. That saves time at the shop.

Make sure it's a Bosch code

Error numbers mean different things on different systems. This page covers Bosch drive systems that show 3-digit codes on Intuvia, Kiox, Purion, Nyon or SmartphoneHub displays. Purion displays may show only the last two digits (for example 03 for 503). The newer Bosch smart system shows 6-digit codes instead; look those up on Bosch's site for now.
